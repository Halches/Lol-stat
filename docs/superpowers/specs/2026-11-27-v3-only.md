# LoL Helper: только v3

Старые клиенты v1/v2 сохраняются только в архиве. Действующее Windows-приложение — v3, точка входа `beta/desktop/qt.py`.

Исходники старого клиента и его проверочные workflow перемещаются в `archive/legacy-app/`. Модули и каталог, которые использует v3, размещаются в `beta/`; генератор каталога — в `tools/`. Сайт и его сборка продолжают работать. Активные инструкции, документация и CI описывают только v3.

Проверка: набор тестов `beta/tests`, генерация каталога, сборка EXE и запуск `--smoke`. Версия и заметки выпуска обновляются, поскольку меняются пути исходников, включённых в EXE.
