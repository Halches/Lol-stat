# Архив LoL Helper v1/v2

`app/` — последний снимок прежнего Windows-приложения после исправлений,
внесённых в коммите `e36d925`. `workflows/` и `tools/` — его прежние сборки
и служебные скрипты. Архив хранится для истории и не используется v3.

Последний опубликованный выпуск v2: [v2.0.7](https://github.com/Halches/Lol-stat/releases/tag/v2.0.7).
Для запуска старого исходного дерева используйте соответствующий Git-тег;
пути внутри этого снимка сохранены как исторические.

Единственное действующее приложение: `beta/desktop/qt.py`.
