# История матчей — отдельный прототип Qt Quick

Проверка переноса графического слоя LoL Helper на **PySide6 + QML**.
Основное приложение на Tkinter, его запуск, графики, настройки, обновление и игровые оверлеи не изменены.
Прототип не записывает настройки и архив, не подключается к LCU и не запускает фоновые службы приложения.

## Запуск на Windows

Нужен Python 3.11 или новее и полный checkout этой ветки, включая `app/data.json`, шрифты и `app/ui_assets`.
Дважды открыть `run_windows.cmd`. Первый запуск скачает зависимости в отдельное окружение
`%LOCALAPPDATA%\LoLHelperQtPreview\venv`. Основную установку LoL Helper это не заменяет.
Это запуск из исходников, не установщик EXE. Скрипт подготовлен, но Windows-прогон ещё не выполнен.

Ручной запуск из корня репозитория:

```powershell
py -3 -m venv .venv-qt-preview
.venv-qt-preview\Scripts\python -m pip install -r app/dev/qt_history/requirements.txt
.venv-qt-preview\Scripts\python app/dev/qt_history/main.py
```

Данные можно выбрать аргументами `--data PATH --profile halch`. Доступен также профиль `drv` из текущего архива.
Иконки можно заменить через `--assets PATH`, формат совпадает с `app/assets.json`.

## Что уже работает

- История из существующего локального архива и прежние расчёты `history_model`.
- Поиск чемпиона/оппонента, фильтры роли, режима, результата и сброс.
- Итоги текущей выборки; отображение неизвестных значений как «—».
- Прокрутка всего отфильтрованного списка с повторным использованием видимых строк.
- Открытие кратких сохранённых данных матча, официальные иконки героев, предметов, заклинаний и ключевой руны.
- Объёмная рамка и панели из общих ресурсов темы, настоящие поля и списки Qt, адаптация строк к узкому окну.

Другие страницы, загрузка из клиента, полный разбор матча и оверлеи пока остаются в основной программе.
Не подключённые в прототипе кнопки отключены. Новые игровые функции не добавлялись.
Штатная системная строка заголовка сохранена: перетаскивание и изменение размера выполняет ОС.
Скриншоты проверки показывают клиентскую область окна без системной строки заголовка.

## Визуальная и функциональная проверка

```bash
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  python app/dev/qt_history/main.py --capture-dir /tmp/qt-history-review
```

Скрипт `review.py` взаимодействует с настоящим окном через QtTest: нажимает кнопки,
вводит поиск, выбирает роль/режим, открывает матч, прокручивает архив и меняет размер окна.
Он сохраняет PNG через `QQuickWindow.grabWindow()` и отчёт `checks.json`; ошибки дают ненулевой код выхода.
Проверяемые клиентские размеры: 940×640, 1060×740, 1366×768, 1536×864 и 1920×1080.

Подтверждено в Linux с программным рендерером Qt. Это не проверка Windows,
аппаратного рендерера, смешанного DPI на нескольких мониторах или нагрузки во время игры.
Времена `filter_ms` измеряют только Python-фильтрацию и формирование модели, не FPS интерфейса.
Решение о полном переносе следует принимать после проверки этого прототипа на Windows.

## Ресурсы

`icons.json`: портреты/предметы из ранее подготовленных ресурсов LoL Helper;
заклинания и ключевые руны — Riot Data Dragon 15.21.1, загружены только при подготовке прототипа.
При запуске сети для иконок не требуется. Шрифты и декоративные изображения используются из
`app/fonts` и `app/ui_assets`; исходные лицензии и описание происхождения находятся там же.

Прототип подготовлен локально в ветке `design/qt-history-prototype`. Релиз и публикация не выполнялись.

## Доработка под исходный графический образец

Для панелей, обычных и выбранных кнопок подготовлены три отдельные нарисованные
PNG-поверхности в `painted/`. Мягкие блики, отражения, свечение и тень находятся
в самих изображениях. QML располагает поверх них живой текст и иконки.
Углы масштабируются по девяти частям; прозрачный фон PNG сохранён.
Поля сохраняют затемнённую внутреннюю поверхность. Контраст заднего фона снижен.
Уточнены плотность меню, высота строк, разделители, портреты и цветные метки результата.
Анимация и постоянное размытие не используются.

Для одинаковых заголовков и цифр в комплект добавлен PT Serif (обычный и жирный),
источник: https://github.com/google/fonts/tree/main/ofl/ptserif .
Лицензия SIL OFL сохранена в `fonts/OFL.txt`. Загрузка шрифта проверяется в `review.py`.
Данные, расчёты и доступные действия прототипа сохранены.
Исходные промпты и способ подготовки графики: `painted/PROMPTS.md`.
