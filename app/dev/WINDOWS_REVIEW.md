# Проверка приложения перед выпуском

Проверять ветку `design/draft-native`, не текущий опубликованный EXE.
Windows в этой среде недоступна. Python-симуляции Linux не подтверждают
работу Win32, распознавание настоящей игры или звучание голоса.

## Запуск исходников

Нужен Python 3.12 с Tkinter. В корне копии ветки:

```powershell
py -3.12 -m venv .review-venv
.review-venv\Scripts\python -m pip install pillow edge-tts==7.3.1 pywebview==5.3.2 opencv-python-headless==4.11.0.86 numpy==2.2.6
.review-venv\Scripts\python app/dev/windows_review.py
```

Сначала выполняются все unit-тесты и проверки ядра. Проверка использует
собственный профиль `development-review` внутри папки приложения в AppData.
Рабочие настройки не подменяются. Автоэкспорт изначально выключен; клиент
изменится только при явном экспорте или включении автоэкспорта в этой проверке.
Опубликованный EXE не заменяется, обновление и телефон не запускаются.
При закрытии главного окна формируется `review-report.txt` с диагностикой.
Отсутствие Piper в исходниках не означает проверку встроенного голоса EXE:
для голоса выбери установленный доступный движок. Упакованный EXE всё равно
нужно отдельно собрать и проверить на Windows перед выпуском.

## Ручной прогон

| Сценарий | Что проверить |
|---|---|
| DPI 100%, 125%, 150% | Главная, история и раскрытый матч, чемпион, пул, настройки: текст и кнопки доступны. |
| Драфт | Десять равных карточек, правильные роли напротив, синергия слева и контрпики справа; общий верх/низ центра. |
| Второй монитор | Начало драфта открывает второе окно на нём; перенос и размер сохраняются. |
| Ручное закрытие | Окно не возвращается на следующем опросе; открывается кнопкой и при новом драфте. |
| Экспорт | Популярная, по винрейту, матчап, оффмета и игрок: в клиент попадают именно показанные руны/предметы. |
| Отмена экспорта | Быстро поменять роль/чемпиона/источник или завершить драфт: оставшиеся операции останавливаются. |
| Драфт → игра → итог | Правильный профиль, обновление показателей, ручное закрытие, итог без старых данных. |
| Tab | Нажатие/отпускание, красно-синий баланс стоимости предметов, автоподгонка к настоящей таблице. |
| Закрепление | Все семь виджетов: закреплённое тело пропускает клик даже с Alt; значок позволяет открепить. Tab без булавки. |
| Сеть и клиент | Недоступность, перезапуск, короткая пауза: нет ложных нулей, старых повторов и подмены источника. |
| Режимы | Ущелье, ARAM, Арена и быстрая очередь: нет таймеров/советов Ущелья там, где они неприменимы. |
| Звук | Голос, сигнал, общая громкость, mute, ошибка и fallback движка. |

Для замечания нужны действие, ожидаемый результат, фактический результат,
масштаб Windows и снимок экрана. Приложить отчёт; пароли и ключи не нужны.

## Отдельный проверочный EXE

Подготовлен `.github/workflows/app-review.yml`: Windows, Python 3.12,
полные тесты, упаковка `LoLHelper-Review.exe` и автоматический запуск
`--smoke-test`. Результат — артефакт Actions на 14 дней, без релиза и
изменения основной версии. Права workflow ограничены чтением репозитория.
Запуск от push ограничен веткой `design/draft-native`; workflow основной
публикации не вызывается.

Упакованный запуск использует `development-review` и не запускает себя
повторно через `python -m unittest`. Тесты выполняются перед сборкой.
Smoke-проверка не обращается к игре и не подтверждает голос или экспорт:
она проверяет создание интерфейса и наличие основных ресурсов.

Статус: подготовлено и проверено локально; Windows-сборка ещё не запускалась.
Для неё текущие изменения должны попасть в отдельную ветку GitHub.
