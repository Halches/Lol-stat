# Голосовой помощник Windows-беты

Отдельный пункт «Голосовой помощник» в левом меню. Включение, голос,
громкость и все переключатели сохраняются автоматически в настройках беты.
По умолчанию помощник выключен. Проверить голос и примеры можно без матча.

Категории: общие, верх, лес, центр, низ, поддержка. Общие переключатели
действуют для любой роли, остальные сохраняются отдельно для каждой роли.
Роль берётся из драфта того же матча, явной позиции Live Client Data или
ручного выбора. Популярная роль чемпиона не используется для угадывания.

В игре используются исключительно заранее подготовленные записи из
`assets/voice-pack`. Основной голос — Светлана (Microsoft). Silero исключён
из помощника, инструмента подготовки записей и поставляемых файлов. Дополнительные
одобренные голоса Microsoft: Ава, Эмма, Эндрю и Брайан. В меню и сборку
попадают только голоса с полным набором из 40 фраз. Выбранный голос сохраняется;
исходный голос — Светлана. В приложение
не включены модели синтеза, ключи API, загрузчики голосов или распознавание микрофона.
Озвучка искусственная. Фразы с названиями чемпионов/предметов заменены
универсальными. Фарм сравнивается с явно заданной целью, не с выдуманной
исторической нормой. Исторические маршруты лесника не озвучиваются.

Все пять голосов готовы полностью: по 40 фраз, всего 200 записей.

## Жизненный цикл

- Автоматические подсказки работают только при подтверждённом матче EUW
  Solo/Duo (420), данных активного игрока, карте 11 и режиме CLASSIC.
- Загрузка снимков и воспроизведение идут в отдельных потоках. Qt не ждёт
  сеть, синтез или окончание записи. Воспроизведение Windows MCI асинхронное.
- В очереди не больше двух фраз, срок ожидания — пять секунд. Приоритетные
  подсказки вытесняют менее важные. Перекрывающиеся окна ганка не дублируют запись.
- Смена матча/аккаунта, завершение игры, выключение, смена настроек, потеря
  данных и закрытие окна отменяют речь. Запоздавший ответ предыдущего матча
  игнорируется. При кратком разрыве сохраняется история подсказок текущего матча.
- Застывшее игровое время, неверные/неполные данные и GameEnd приостанавливают
  речь. Смерть игрока, покупка предмета и потраченное очко отменяют уже неактуальные
  напоминания. Ошибки воспроизведения отображаются во вкладке.

## Источники правил

Обработка событий переиспользует классические `core.Game` и `core.Engine`.
Тип лесника и окна ганков — явно обозначенные эвристики. Событие убийства
не используется для определения позиции лесника. Сравнение уровней и предметов
требует известной роли оппонента.

Данные матча: [Riot Live Client Data](https://developer.riotgames.com/docs/lol#game-client-api_live-client-data-api).
Расписание объектов унаследовано из классического приложения, включая изменения
[26.1](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/)
и [25.09](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-09-notes/).
Таймер не является наблюдением за объектом. Голосовые записи на 60/30 секунд
не проигрываются, если соответствующее окно пропущено при позднем подключении.

## Подготовка записей

Инструмент `beta/tools/record_voice_pack.py` запускается только разработчиком.
Для Microsoft нужен пакет edge-tts и интернет на этапе подготовки. Игроку они не нужны.

```powershell
# Из beta, используя доступный Python с edge-tts:
python tools/record_voice_pack.py --voices svetlana
python tools/record_voice_pack.py --voices ava emma andrew brian --jobs 2
python -X utf8 -m unittest discover -s tests
python desktop/qt.py --smoke
```

Манифест фиксирует хэш текста и файла и размер. Неполный
набор не предлагается пользователю как готовый голос. При изменении текста
необходимо заново записать соответствующие фразы.
Инструмент сохраняет успешные записи сразу, проверяет хэши перед повторным
использованием и продолжает незавершённый набор при повторном запуске. Число
одновременных запросов ограничено; сбой одной записи не отменяет остальные.

Проверки на фикстурах и нативном окне не заменяют тест настоящего матча,
игрового аудиомикшера и выбранного устройства вывода.
