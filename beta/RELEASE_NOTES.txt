LoL Helper v3.0.9

• Основной Windows-клиент теперь полностью собирается из beta/: ядро, связь с клиентом League of Legends и каталог данных находятся рядом с кодом v3.
• Код прежнего приложения v1/v2 и его проверочные workflow перенесены в архив. Функции и пользовательские настройки v3 сохранены.

Изменения 3.0.8:

• Файл EXE использует логотип LoL Helper вместо стандартной иконки Python. Встроены размеры от 16 до 256 пикселей для Проводника и ярлыков Windows.

Изменения 3.0.7:

• Последний подтверждённый аккаунт, ранги и загруженная история сохраняются после закрытия клиента и перезапуска приложения.
• Сохранённые данные явно помечены. При подключении другого аккаунта его подтверждённый профиль заменяет предыдущий без смешивания истории.
• Отдельная авторизация не требуется; пароли и токены клиента в профиль не записываются.

Изменения 3.0.6:

• Исправлена невидимость Tab: прозрачная область Qt получает фактический размер до показа, без повторного изменения размера на каждом кадре.
• Перемещённые оверлеи сохраняют позиции между матчами и перезапусками Windows-приложения. Старые сохранённые координаты восстанавливаются.
• «До покупки» читает выбранную вами иконку справа от золота, показывает недостающее золото с учётом купленных компонентов. Предмет из сборки больше не подставляется.
• Неуверенное распознавание скрывает подсказку; источник, предмет, уверенность и статус доступны через API.
• Живые оверлеи и помощник подключены к многопользовательской тренировке на Ущелье (3140), без рейтингового импорта и автоматического разбора тренировки.

Изменения 3.0.5:

• Подтверждённая рамка Tab больше не сбрасывается при загрузке портретов и изменении порядка игроков в ответе API.
• API показывает причины отсутствия Tab: состояние клавиши, переключателя, данных, игрового окна и распознавания.

Изменения 3.0.4:

• Стабилизирована рамка оверлея Tab: мелкие колебания распознавания больше не двигают окно.
• Краткие пропуски портретов не заставляют показатели мерцать; смена порядка строк сбрасывает устаревшие сопоставления.
• Исключены повторные изменения размера Qt перед установкой физических координат окна.

Изменения 3.0.3:

• Исправлен отказ импорта, когда gameflow хранит ID предыдущей игры, а выбор чемпионов уже отдаёт новый драфт.

• Голос, текст и звуковой сигнал можно независимо выбирать для каждой отдельной фразы.
• У каждой фразы есть сброс к общим настройкам; переключатели доступны через API.

• Оверлей Tab привязан к рамке таблицы счёта, а показатели — к распознанным строкам чемпионов.
• Стороны команд определяются по портретам: полоса и стрелки учитывают расположение вашей команды.
• При отпускании Tab оверлей скрывается; нераспознанные строки не получают чужие значения.

Изменения 3.0.2:

• Поддержка драфта, импорта и помощника в рейтинговом Flex EUW.
• Живые карточки показателей, стоимости предметов, сравнения линии и выбранной сборки.
• В рабочих оверлеях сохранены портреты, иконки и графическое оформление предпросмотра; значения берутся из текущего матча.
• Индивидуальное отключение фраз, текст поверх игры, звуковой сигнал вместо голоса.
• Состояния и управление новыми функциями доступны через локальный API.
• Карточка покупки показывает полную цену и наличные без вычета компонентов.
• Карточка объектов показывает прошедшее время с подтверждённого события, без отсчёта респавна.

Исправления предыдущего выпуска:

• Исправлена загрузка профиля EUW вне лобби: запускать матч для подключения больше не нужно.
• Главная показывает состояние подключения и полезные действия вместо повторяющихся пустых блоков.
• Просмотр сборок явно доступен без игры; добавлен пример заполнения поиска. Импорт сохраняет проверки драфта.
• Игровые настройки размещены первыми, необязательный адрес сайта перенесён в дополнительные настройки.
• Демонстрационные оверлеи собраны в сворачиваемую «Лабораторию» и доступны только в предпросмотре.
• В узком окне навигация сворачивается в панель иконок; улучшены читаемость и доступность переходов.
• Добавлено полное управление интерфейсом через локальный API: кнопки, поля, модели данных, окна и оверлеи.
• Каждую копию приложения можно адресовать по PID; команды не переключаются на другой процесс.
• Исправлена отрисовка карточек рангов при загрузке данных и изменении размера окна.

API и правила подключения новых функций описаны в beta/desktop/API.txt и AGENTS.md.
Игровые данные для демонстрационных оверлеев пока не подключены.
Обновление устанавливается по кнопке и не перезапускает приложение во время драфта или матча.
