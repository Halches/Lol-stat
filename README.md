# Разбор игр Halch и DrVoldemar

Статистика и разбор игр League of Legends (EUW) по данным Riot API.
Сайт: https://halches.github.io/Lol-stat/

## Автообновление

Workflow `.github/workflows/update.yml` раз в 30 минут спрашивает Riot API, появились ли новые игры.
Если нет, сразу завершается. Если есть, докачивает только их, пересобирает `index.html` и пушит.

Нужен секрет репозитория `RIOT_API_KEY` (Settings → Secrets and variables → Actions).
Дев-ключ живёт сутки, для постоянной работы нужен Personal API Key.
Без секрета workflow просто пропускает запуск. Запустить вручную: Actions → «Обновление игр» → Run workflow.

## Скрипты (`tools/`)

- `fetch.py` — скачивает матчи. С `INCREMENTAL=1` берёт последние 20 игр каждого и качает только те, которых нет в `seen.json`; без него — весь сезон с `SEASON_START`.
- `analyze.py` — считает статистику и добавляет новые игры в `games.json`.
- `icons.py` — иконки и названия из Data Dragon (докачивает только новые в `icons.json`).
- `build.py` — собирает страницу из `template.html`.

## Обновление версии в Claude (с тренером)

Если заданы секреты `CLAUDE_FIRE_URL` и `CLAUDE_FIRE_TOKEN`, после каждой публикации новых игр workflow запускает
задачу Claude «Обновить сайт LoL в Claude», которая перекладывает свежий `index.html` в артефакт.
URL и токен берутся на claude.ai/code/routines → задача → Edit → Trigger → API.

## Настольное приложение 2.0 — Qt

Запуск из исходников: Python 3.12, `pip install -r app/requirements.txt`,
затем `python app/lolhelper.py`. Основное окно и оверлеи используют PySide6;
старые Tk-модули оставлены в репозитории для сравнения и восстановления,
но не импортируются основным приложением и не включаются в EXE.

`python app/qt_review.py` проверяет реальные окна с временными настройками
и обозначенными демонстрационными данными клиента. `QT_REVIEW_OUT` задаёт папку
снимков и отчёта. Linux: можно использовать `QT_QPA_PLATFORM=offscreen`.
На Windows проверка также проверяет стили закрепления и пропуска кликов.

Номер выпуска задаётся в `app/release-version.txt`; перед следующим выпуском
его нужно увеличить. Сборка `python app/build_windows.py` выполняется в Windows
после подготовки игровых ресурсов, архива матчей и встроенного голоса workflow.
Проверка ветки: «Проверка полного приложения Qt». Основной workflow публикует
новый EXE только после успешной самопроверки. Заметки: `app/RELEASE_NOTES.md`.

Точка восстановления предыдущего приложения: `restore/pre-qt-2026-11-05`,
выпуск v1.0.38. Исходные пользовательские настройки перед переходом на Qt
сохраняются в `%APPDATA%/LoLHelper/settings.json.pre-v2` один раз, без перезаписи.
