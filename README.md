# Разбор игр Halch и DrVoldemar

Статистика и разбор игр League of Legends (EUW) по данным Riot API.
Сайт: https://halches.github.io/Lol-stat/

`tools/` — скрипты сборки: fetch.py (скачать матчи, нужен RIOT_API_KEY в окружении) → analyze.py → icons.py → build.py (собирает страницу из template.html).
